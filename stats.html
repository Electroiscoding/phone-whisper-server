shield 4. System Boundaries & Best Practices

Memory Limit (4 GB RAM): The kernel is optimized for datasets up to 1 GB in memory. Loading uncompressed 5 GB files into memory will trigger the Linux out-of-memory (OOM) killer.
Colab & Kaggle Compatibility: Code relying on apt-get or fc-cache is automatically intercepted and mapped to Android Termux user space. System fonts are mapped directly to /system/fonts/.

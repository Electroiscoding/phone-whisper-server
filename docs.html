04. Elastic Memory Governor & JIT Eviction

Because 4GB RAM must accommodate Whisper, Qwen, Kokoro, BGE, and the Swades agent simultaneously, the gateway employs an autonomous Dynamic Elastic JIT Governor.

🧠 GOVERNOR POLICY: dynamic_elastic_jit

Models are not kept perpetually loaded in memory. Instead, when an API call arrives (e.g., /v1/chat/completions), the governor evaluates RAM pressure. If available memory drops below 400MB, idle models with elapsed timeout > 75.0s are instantly evicted from RAM.

JIT Eviction Order: BGE-Reranker (380MB) → Qwen 2.5 (340MB) → Whisper Base (140MB) → Kokoro TTS (85MB)
CONTAINER RUNTIME: Alpine Linux via PRoot

For code execution safety and environment isolation, the Swades autonomous agent runs inside an unprivileged Alpine Linux container (via proot-distro). All modifications occur inside isolated git worktree branches (swades/patch-<job_id>).

06. Sub-Microsecond Storage Engine

The phone datacenter object storage engine uses a two-tier dual-memory architecture combining pure RAM hash index reflection with durable eMMC flash storage.

⚡ Tier 1: L1 In-Memory Reflection

Every stored object is indexed in an in-memory hash map (SwadesObjectStore). Key validation, existence verification, and metadata queries reflect in <0.0001 ms (<45 nanoseconds) without touching flash storage.

💾 Tier 2: eMMC Sandboxed Flash

Objects > 64KB are streamed directly to physical storage pools using SHA-256 sandboxed paths. Tenancy boundaries are strictly enforced with zero cross-tenant contamination.

07. Security Shield, Auth Vault & SQLite WAL

SwadesSecurityShield Rate Limiting

Protects edge endpoints against DDoS and credential stuffing with an in-memory sliding-window limiter capped at 120 requests/minute per IP. Exceeding limits returns HTTP 429 with Retry-After: 60.

PBKDF2 Password Vault & Scoped Tokens

User accounts in auth.db use PBKDF2 with HMAC-SHA256 (100,000 rounds) and 32-byte salts. API keys are generated as sk_swades_<random_hex> with granular scopes:

  • full: Complete read, write, delete, and table management permissions.
  • read_only: Can read objects and stream CDN files; writes return HTTP 403.
  • write_only: Can upload objects; read operations return HTTP 403.
SQLite Concurrency & High-Throughput Pragmas

The internal database engine operates in WAL (Write-Ahead Logging) mode to prevent write lock starvation: 

PRAGMA journal_mode = WAL;
PRAGMA synchronous = NORMAL;
PRAGMA temp_store = MEMORY;
PRAGMA mmap_size = 268435456; /* 256MB memory mapping */
PRAGMA cache_size = -64000;   /* 64MB RAM page cache */
PRAGMA busy_timeout = 5000;

🚨 Error Code Catalog & Troubleshooting

Standardized HTTP error responses and actionable diagnostic resolutions.

Status Error Code Root Cause Actionable Resolution
400 BAD_REQUEST Missing required parameters or malformed JSON. Verify Content-Type is application/json and payload matches schema.
401 UNAUTHORIZED Missing or invalid Bearer API key on protected route. Pass Authorization: Bearer sk_swades_... in request headers.
403 FORBIDDEN API key lacks required scope (e.g. read_only key trying to write). Generate a key with full or write_only scope in Console.
404 NOT_FOUND Object not found in tenant sandbox. Ensure tenant ID and path match previous PUT upload destination.
429 RATE_LIMITED IP exceeded 120 requests/minute sliding window threshold. Back off and retry after the duration specified in Retry-After.
500 SERVER_ERROR Uncaught exception or model loading failure. Check gateway.log or verify phone RAM availability via /telemetry.

09. Client SDKs & Code Libraries

Lightweight, zero-dependency wrapper libraries for instant drop-in integration with your backend or frontend stack.

🐍 Python 3 SDK (Zero-Tassel Client) 
import requests

class PhoneDatacenterClient:
    def __init__(self, base_url="https://phone-whisper-server.pages.dev", api_key=None):
        self.base = base_url.rstrip("/")
        self.headers = {"Authorization": f"Bearer {api_key}"} if api_key else {}

    def transcribe(self, audio_path):
        with open(audio_path, "rb") as f:
            r = requests.post(f"{self.base}/v1/audio/transcriptions", files={"file": f})
            return r.json()

    def chat(self, prompt, system_prompt="You are a helpful assistant."):
        r = requests.post(f"{self.base}/v1/chat/completions", json={
            "messages": [
                {"role": "system", "content": system_prompt},
                {"role": "user", "content": prompt}
            ]
        })
        return r.json()["choices"][0]["message"]["content"]

    def upload_object(self, remote_path, data_bytes):
        r = requests.put(f"{self.base}/v1/storage/objects/{remote_path}", data=data_bytes, headers=self.headers)
        return r.json()
⚡ JavaScript / TypeScript Client 
export class PhoneClient {
  constructor(private baseUrl = 'https://phone-whisper-server.pages.dev', private apiKey?: string) {}

  async transcribe(audioBlob: Blob) {
    const form = new FormData();
    form.append('file', audioBlob, 'audio.wav');
    const res = await fetch(this.baseUrl + '/v1/audio/transcriptions', { method: 'POST', body: form });
    return res.json();
  }

  async chat(prompt: string) {
    const res = await fetch(this.baseUrl + '/v1/chat/completions', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ messages: [{ role: 'user', content: prompt }] })
    });
    const data = await res.json();
    return data.choices[0].message.content;
  }
}

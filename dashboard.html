1. One-Line SQL Query via Requests 
import requests

res = requests.post("https://phone-whisper-server.pages.dev/v1/db/sql",
    headers={"x-api-key": "YOUR_KEY", "x-project-id": "YOUR_PROJECT"},
    json={"query": "SELECT * FROM items;"}).json()
print(res["result"]["rows"])
2. One-Line File Upload to Storage 
with open("photo.jpg", "rb") as f:
    res = requests.put("https://phone-whisper-server.pages.dev/v1/storage/objects/photo.jpg",
        headers={"x-api-key": "YOUR_KEY"}, data=f.read()).json()
print("CDN URL:", res["object"]["url"])
1. One-Line cURL for AI Agents (CRUD SQL) 
curl -X POST https://phone-whisper-server.pages.dev/v1/db/sql   -H "Content-Type: application/json"   -H "x-api-key: YOUR_KEY"   -H "x-project-id: YOUR_PROJECT"   -d '{"query": "SELECT * FROM items;"}'
2. Upload Any File to Object Storage 
curl -X PUT https://phone-whisper-server.pages.dev/v1/storage/objects/document.pdf   -H "x-api-key: YOUR_KEY"   --data-binary @document.pdf

Architecture

How It Works

From your microphone to on-device neural processing and back in ~1 second.

1
Audio Capture & 16kHz PCM
Microphone voice is captured and resampled directly into standard 16kHz 16-bit Mono WAV in the browser.
2
Anycast Edge
HTTPS POST request reaches Cloudflare's global edge network nearest to the client (sub-10ms).
3
QUIC Tunnel
Cloudflare multiplexes the request through an encrypted QUIC tunnel directly into the phone's cloudflared daemon.
4
On-Device AI
Whisper C++ engine executes neural decode in phone RAM using 4 ARM CPU threads, returning structured text.

Drop-in snippet for Google Colab, Jupyter Notebooks, FastAPI, Flask, or backend services: 

import requests

API_ENDPOINT = "https://hardly-assembly-guides-cache.trycloudflare.com/inference"

def transcribe(audio_path: str, response_format: str = "json") -> dict:
    with open(audio_path, "rb") as f:
        files = {"file": f}
        data = {
            "temperature": "0.0",
            "response_format": response_format  # 'json', 'text', 'srt', 'vtt'
        }
        res = requests.post(API_ENDPOINT, files=files, data=data, timeout=60)
        res.raise_for_status()
        return res.json() if response_format == "json" else res.text

# Run transcription
result = transcribe("my_voice.wav")
print("Result:", result.get("text"))

Native Fetch with zero npm dependencies — works in Node.js (v18+), React, Vue, Next.js, and Browser: 

const API_ENDPOINT = "https://hardly-assembly-guides-cache.trycloudflare.com/inference";

async function transcribeAudio(audioBlobOrBuffer, format = "json") {
  const formData = new FormData();
  formData.append("file", audioBlobOrBuffer, "audio.wav");
  formData.append("temperature", "0.0");
  formData.append("response_format", format);

  const res = await fetch(API_ENDPOINT, {
    method: "POST",
    body: formData,
  });

  if (!res.ok) throw new Error(`HTTP Error ${res.status}`);
  return format === "json" ? await res.json() : await res.text();
}

Send audio directly from any command-line or bash pipeline: 

curl -X POST "https://hardly-assembly-guides-cache.trycloudflare.com/inference" \
  -H "Content-Type: multipart/form-data" \
  -F "file=@sample.wav" \
  -F "temperature=0.0" \
  -F "response_format=json"

REST API Parameters

Parameter Type Default Description
file Binary File Required Audio file payload (WAV, MP3, OGG, M4A, FLAC, WEBM)
response_format String json Output format: json, text, srt, vtt, verbose_json
temperature Float 0.0 Sampling temperature (0.0 for highest accuracy)
no_speech_thold Float 0.6 Silence / no-speech probability threshold
